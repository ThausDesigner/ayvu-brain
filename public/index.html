    02 · PROVEDORES DE IA

    Conectado aos 4 principais provedores sem vendor lock-in.

    Suporte a BYOK via API no servidor local (zero erro de CORS, chaves nunca salvas em disco) e lançamento direto das CLIs oficiais em worktrees isolados.

    Claude (Anthropic)

    Chat via Anthropic Messages API no painel Multi-IA e execução de tarefas de código via claude (Claude Code) em worktrees isolados.

    API BYOKCLI claude

    Codex / OpenAI

    Chat e transcrição via OpenAI API e execução paralela de engenharia via codex (Codex CLI) com revisão de diff ao vivo.

    API BYOKCLI codex

    Gemini (Google)

    Chat, transcrição e resumo de áudio em uma única chamada via Gemini API, além de agy (Antigravity) e gemini no terminal.

    API + ÁudioCLI agy / gemini

    Grok (xAI)

    Conectado via API oficial da xAI (api.x.ai/v1) direto no painel Multi-IA com contexto do vault. Sem CLI proprietário necessário.

    API xAI BYOKOpenAI-compat

    03 · ARQUITETURA LOCAL-FIRST

    Programa instalado no SO, memória solta em Markdown.

    Regras de segurança herdadas

    Nenhuma ponte local exposta na internet sem autenticação. O servidor roda exclusivamente em 127.0.0.1.

    Nunca varre Drive/ nem node_modules/

    A listagem do vault usa uma allowlist fechada das pastas de Markdown, ignorando symlinks e repositórios pesados.

    Bloqueio automático de chaves no Markdown

    Qualquer tentativa de salvar um arquivo contendo padrões de API key (Anthropic, OpenAI, Gemini, xAI, GitHub) é recusada antes de tocar no disco.

    Pronto para virar .exe / .dmg com Tauri v2

    A interface já é 100% desacoplada e leve. Quando validada no dia a dia, basta empacotar via GitHub Actions sem sobrecarregar seus 8 GB de RAM.

    04 · VERSIONAMENTO E ROLLBACK

    Cada marco versionado com Git tag para voltar atrás em segundos.

    Instalar no Windows & voltar versão

    Cria atalho no Menu Iniciar e na Área de Trabalho com o ícone da AYVU e abre como janela desktop dedicada (sem barra de navegador).

    # Instalar no Windows (Menu Iniciar + Desktop)
git clone https://github.com/ThausDesigner/ayvu-brain
cd ayvu-brain
npm run install:windows

# Voltar para uma versão anterior a qualquer momento
git tag -l
git checkout v0.1.0
