      1. Entre no Claude Console e abra API keys.
      2. Escolha Create key, dê um nome e vincule à sua conta ou workspace.
      3. Copie a chave na criação. Confira créditos e cobrança no Console.
      Se a chave não aparecer novamente, crie outra no Console.

      OpenAI / Codex
      1. Entre na plataforma OpenAI e selecione seu projeto.
      2. Abra API keys e crie uma chave secreta para esse projeto.
      3. Copie a chave na criação e confira a cobrança da API.
      A cobrança da API é separada da assinatura ChatGPT. Codex CLI pode usar o próprio login; este chat usa API.
      Abrir console 
      Consultar documentação oficial 
      Gemini / Google
      1. Entre no Google AI Studio e abra API Keys.
      2. Use uma chave existente ou escolha Create API key e o projeto.
      3. Copie a chave. Confira cota, permissões e faturamento do projeto.
      O projeto e a chave gerados pelo AI Studio podem ser usados também para transcrever reuniões.
      Abrir console 
      Consultar documentação oficial 
      Grok / xAI
      1. Entre no console da xAI e selecione sua equipe.
      2. Abra API Keys e crie uma chave para usar a API.
      3. Copie a chave e confira os créditos da equipe antes de enviar mensagens.
      A chave é criada no console de desenvolvedores, separado da tela de conversa do Grok.
